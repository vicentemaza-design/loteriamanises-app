# Entrega Lotería Manises

## Qué contiene DEMO y PRODUCTION

DEMO y PRODUCTION contienen el mismo frontend funcional y diseño aprobado.

### DEMO

Frontend autónomo para QA y presentación, con `MockAdapter` y datos mock/sintéticos cuando corresponde. No representa operación monetaria real ni servicios oficiales conectados.

### PRODUCTION

El mismo frontend funcional, preparado para integración con backend y proveedores reales. PRODUCTION no implica que SELAE, Redsys, wallet, ledger, retiradas u otros servicios estén ya conectados, certificados o listos para operación real.

La autoridad de negocio debe residir en backend; los providers mock son exclusivamente para demo/QA.
